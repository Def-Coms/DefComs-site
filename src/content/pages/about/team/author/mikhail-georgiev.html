Автор

Михаил Георгиев

Head of Offensive Security (Pentesting) в DefComs. Специалист по проникващи тестове на уеб/API приложения, облачни среди и червени екипи (Red Teaming).

За автора

Михаил Георгиев ръководи отдела за офанзивна сигурност в DefComs. Той има дълбока експертиза в проникващите тестове и Red Teaming операциите.

Неговата експертиза обхваща:

  • Web application penetration testing
  • API security testing
  • Cloud security assessment (AWS, Azure)
  • Network penetration testing
  • Red Teaming и simulation exercises
