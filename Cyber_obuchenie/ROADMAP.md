# ROADMAP — ShieldAcademy

> Актуален статус на проекта. **Правило:** при всяка нова функция, модул или значима промяна този файл се обновява задължително.
> Последна актуализация: 27.11.2026

## 1. Какво е ShieldAcademy

Платформа за вътрешно обучение на служители по кибер сигурност. Поддържа множество организации с пълна изолация на данни. Цялото съдържание е на български. Технологии: Node.js ≥ 24 + Express + `node:sqlite` (backend), React 19 + Vite (frontend).

## 2. Изградено — статус по области

### 2.1 Учебна платформа (служители)
- [x] Път на обучение с 4 нива: начален, среден, напреднал (3 профила: разработка/сигурност/устройства), управленски
- [x] Постепенно разкриване на модули по месеци (`modules_per_month` в Настройки, 1–6)
- [x] Учене по раздели с проследяване на време + тестове с обяснения на отговорите
- [x] **5 типа въпроси**: single, multi (няколко верни), truefalse, order (подреждане), match (съотнасяне) — разбъркване и картографиране на отговорите, автоматично оценяване
- [x] Варианти на тестовете — разбъркан поднабор от въпроси и отговори при всеки опит
- [x] Многократни опити — взетият тест отключва следващия модул
- [x] Лични цели с график на падежи
- [x] Профил, мои опити с преглед, активност
