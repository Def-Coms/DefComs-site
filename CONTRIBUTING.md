# Начин на работа по сайта

**Спазването на [PLAN.md](./PLAN.md) и на този документ е задължително** за всички (хора и AI асистенти).
Целта: във всеки момент да е ясно какво е изградено и какво остава.

## Правила

1. **Планът е единственият източник на истина.** Преди работа намери задачата в `PLAN.md`. Ако я няма, добави я първо.
2. **Отмятай задачите.** Когато приключиш, смени `[ ]` с `[x]` в **същата промяна** (commit/PR) и обнови „Последна актуализация“.
3. **Важни решения** се записват в таблицата „История на решенията“ в плана.
4. **Не се редактира** `dist/` (генерира се) и `legacy/` (само за справка).
5. **Всичко повтарящо се е в данни или компоненти, не в копиран HTML.** Нов тип страница се прави като шаблон, не се копира на ръка.
6. **Не се променя дизайнът** (`public/styles.css`) без изрично решение, записано в плана.
7. **Адреси без разширения**: линковете са `/services/x`, никога `.html`. `npm run check` трябва да показва `dotHtml: 0`.
8. **Преди да изпратиш работата:** `npm run build` минава без грешки и `npm run check` не показва нови проблеми.
9. **Работа през клонове и Pull Request** (когато има git, задача 4.1): един клон = една задача; никой не пише директно в `main`; всяка промяна има ревю от втори човек.
10. **Една промяна = една цел.** Не смесвай миграция на страници с нови функции.

## Къде е какво

| Какво | Къде |
|-------|------|
| Страници и статии | `src/content/pages/` |
| Меню и футър | `src/data/site.ts` |
| Схема на frontmatter (полета) | `src/content.config.ts` |
| Layout, SEO, компоненти | `src/layouts/`, `src/components/` |
| Генерирани списъци | `src/components/CardList.astro`, `BlogListing.astro` |
| Шаблон за град | `src/components/CityPage.astro`, `src/lib/city.ts` |
| Статични файлове (CSS, JS, снимки, PHP, `.htaccess`) | `public/` |
| Стар сайт (справка) | `legacy/` |

## Често срещани задачи

Команди: `npm install` (веднъж), `npm run dev` (http://localhost:4321), `npm run build`, `npm run check`.

- **Нова статия:** Markdown файл в `src/content/pages/blog/` с `article:` във frontmatter. Картата в блога, JSON-LD и sitemap се появяват автоматично. Образец: съществуваща статия.
- **Нова услуга / термин:** страницата с `card:` във frontmatter (група и ред за услугите) → появява се в списъка. След задача 2.2 / 2.5 се ползва съответният шаблон.
- **Нов град:** файл `src/content/pages/bulgaria/<град>.html` само с frontmatter (`city:`, `card:`), без тяло. Образец: `varna.html`.
- **Промяна в менюто или футъра:** само `src/data/site.ts`.
- **Скриване на страница:** `draft: true`.
- **Страница, която не е за индекс:** `robots: noindex, follow` (изключва се от sitemap).
